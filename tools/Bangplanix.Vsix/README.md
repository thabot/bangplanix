# Bangplanix VS Code Extension

**Bangplanix Report Designer & Live Preview** provides native authoring, validation, and real-time live preview for `.bpx` report templates in Visual Studio Code.

## Features

- ⚡ **Real-time Live Preview**: Side-by-side SVG live preview updating instantly as you edit.
- 📐 **Schema Validation**: Full JSON Schema autocompletion, tooltip documentation, and validation for all `.bpx` properties.
- 🔍 **Diagnostics & Linter**: Real-time error detection for missing bands, invalid expressions, and JSON structure errors.
- ✂️ **Rich Snippets**: Fast scaffolding for reports, bands, text elements, barcodes, and expressions.

## Commands

- `Bangplanix: Open Live Side-by-Side Preview` (`Ctrl+Alt+P` / `Cmd+Alt+P`)
- `Bangplanix: Validate Report Schema & Expressions`
